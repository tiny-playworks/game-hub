# 日麻 UI 改造计划表

## 目标

- 只改 UI 表现与交互层级，不改玩法/算分逻辑。
- 操作按钮改为按条件触发显示：`立直/吃/碰/胡/杠/过`。
- 顶栏收敛信息，调试能力默认隐藏到菜单抽屉。

状态说明：`Todo` / `Doing` / `Done`


| 阶段  | 任务               | 验收标准                                    | 状态   |
| --- | ---------------- | --------------------------------------- | ---- |
| A   | 动作系统重构（移除“更多操作”） | 仅在可执行时出现动作按钮；无动作时不显示动作条；`过`仅在可执行动作出现时显示 | Done |

## 回归清单

- 桌面端：动作条层级清晰，主操作一眼可见。
- 移动端：按钮不遮挡手牌，操作区仍可点击。
- 对局流程：吃/碰/杠/立直/荣/自摸逻辑行为与改造前一致。
- 调试功能：日志开关、回退功能可从菜单进入并正常工作。
