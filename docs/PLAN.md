## 2. 需求排序

### 已完成（归档）

- **占位游戏**：斗地主简化版、升级入门已上线。
- **日麻增强**：流局、本场连庄；和了算分接入 riichi-rs-bundlers；日麻音效（6 个 wav + TTS 补缺）、日麻动画（摸牌/弹窗/高亮）。
- **基础设施**：游戏内 i18n、路由懒加载、国际象棋/围棋/更多成就、包体分析、PWA 等（详见 [REPO_WIKI §5.1](REPO_WIKI.md#51-已完成归档)）。

### 待做（按优先级）


| 优先级    | 项              | 说明                         |
| ------ | -------------- | -------------------------- |
| **P2** | 麻将变种 / 更多语音与动画 | 按需：其他麻将或游戏加音效与动画；更多麻将规则变种。 |
| **P3** | 在线多人 / SSR     | 需后端与架构，单独排期。               |


**下次迭代建议**：从 **P2** 按需选取（例如日麻更多语音与动画、或新麻将规则）。
