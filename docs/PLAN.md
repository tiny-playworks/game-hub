# 开发计划与需求排序

**维护说明**：主维护者长期单人开发（约八成时间）；文档面向**后续可能加入的协作者**——读一遍即可跟上主线，细节以链接文档为准。

**权威主线**：当前迭代目标与阶段拆分以 **[player-meta-roadmap.md](player-meta-roadmap.md)** 为准（玩家档案 → 成长 → 音频 → 游戏感 → 角色预研 → 雀士 1.0）。本文做**总览、范围边界与文档索引**，不重复 roadmap 全文。

**近期执行细则**：P0/P1/P2（大厅 2.0、成长闭环 2.0、角色骨架）的**可执行说明书**见 **[player-meta-next-plan.md](player-meta-next-plan.md)**（含验收标准、允许/禁止修改范围、派单方式）。

---

## 1. 范围与原则

| 项 | 说明 |
| --- | --- |
| **麻将** | **只做日本立直麻将（日麻）**，不排期其他麻将规则变种；日麻体验与资源可继续加深。 |
| **合集内其他游戏** | 16 款已上线；除日麻外以小维护、bugfix、轻量体验优化为主，不单独开「新玩法大版本」除非另有决定。 |
| **SSR / 在线多人** | **不作为本 Web 仓库的当前迭代目标**；若未来做独立 App，多在后半阶段再考虑联网与架构升级。 |

**产品顺序（单主线时的推荐）**：本地玩家档案 → 成就 / 称号 / 任务 → 音频系统 1.0 → 角色系统预研 →（最后再）雀士角色 1.0。先建立**身份感 + 反馈感 + 成长感**，再上大资源量的角色内容。

## 2. 主线阶段速览

与 [player-meta-roadmap.md 第 4 节](player-meta-roadmap.md#4-分阶段计划)一致，六阶段如下：

| 阶段 | 目标 | 重点产出 | 重量 |
| --- | --- | --- | --- |
| **1** | 玩家档案 1.0 | 昵称、头像、称号、玩家卡、本地存档 | 轻 |
| **2** | 成长系统 1.0 | 成就点数、进度成就、统计、每日任务 | 中 |
| **3** | 音频系统 1.0 | 音量分组、BGM、UI 音效、日麻系统语音包 | 中 |
| **4** | 游戏感改造 | 首页大厅化、结算页、解锁反馈、继续游玩 | 中 |
| **5** | 角色系统预研 | 角色数据结构、立绘位、语音包位、解锁关系 | 中 |
| **6** | 雀士角色 1.0 | 角色选择、立绘、角色语音包、角色资料 | 重 |

**阶段进度（2026-04-05）**：
- 阶段 1/2：已落地并持续小迭代
- 阶段 3：暂缓（音频方案待定）
- 阶段 4：进行中（已落地“成就解锁全局弹窗 + 日麻结算摘要增强”）
