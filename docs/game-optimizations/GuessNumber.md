# 猜数字 (Guess Number) 重制优化计划

## 1. 当前现状与痛点
- **交互极简**：基本就是一个 `<input>` 框加上几句提示文字（偏大了、偏小了），更像是一个控制台程序而非游戏。
- **成就感极低**：缺乏视觉上的奖励感。

## 2. 视觉与动效升级 (Juice & Polish)
- **数字仪表的质感**：采用拟物化设计，比如使用转盘式的“密码锁（Safe Dial）”旋转动画来输入数字，或者将数字呈现为一个复古的 Nixie Tube（辉光管）或 LED 跑马灯显示屏。
- **进度缩圈**：用一个可视化的弧形进度条或者温度计，提示玩家猜测的数字距离目标是“越来越热（红）”还是“越来越冷（蓝）”。
- **确认动作**：每次提交猜测，数字像老虎机一样滚动，最后“咔哒”一声定格。

## 3. 听觉与反馈体验
- 机械转盘/拨动数字时的滴答声。
- 猜中时保险柜打开的沉重机械锁解开声、撒花的欢呼声。

## 4. 机制与周边创新
- **Mastermind (珠玑妙算) 模式进阶**：从单纯提示大小，进化为“几A几B”（即猜对几个数字，且位置对了几个），大幅提升逻辑推理的深度和乐趣。
- **炸弹拆除情境**：包装一层外衣——玩家正在拆除一枚定时炸弹，猜数字是解开引线的密码。时间在一点点流逝，猜错一次还会加速时间，营造影视级的压迫感。

## 5. 代码重构指引
- 输入逻辑防抖与格式化。
- 将传统的 `alert()` 或普通文字段落，替换为状态驱动的动画气泡日志栏（Logs），展示玩家之前猜过的所有记录以及对应的热度提示。
