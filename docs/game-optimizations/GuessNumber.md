# 猜数字优化评估

## 源码入口

- 页面：`src/pages/GameGuessNumber.tsx`
- 样式：`src/pages/guess-number.css`

## 当前状态

当前版本已经包装成“拆弹密码”主题，有倒计时、数字键盘、历史日志、热度提示、错误扣时和高分记录。它不再是普通 input 加提示文字。

## 已落地优化

- 倒计时失败和猜错震动反馈。
- 数字键盘适配移动端。
- 历史记录会展示猜测次数和热度。
- 高分按剩余时间写入 `useGameStore`。
- 页面视觉主题完整，第一眼能看出玩法情境。

## 待优化问题

- 热度提示仍是英文：`Too High`、`Too Low`、`Hot` 等，和中文站点不一致。
- 主要输入依赖屏幕键盘，桌面键盘 Enter、Backspace、数字键支持不明确。
- 规则函数留在页面里，后续想加 Classic/Mastermind/限时模式会挤在同一文件。
- 倒计时 `useEffect` 每秒重建一次 interval，能工作但不够直接。
- 当前高分只看剩余时间，不区分猜测次数，可能鼓励运气而不是推理效率。

## 建议重构

- 抽出 `src/lib/guessNumber.ts`：生成答案、判断热度、计算扣时、计算本局评分。
- 输入层统一处理实体键盘和屏幕键盘。
- 评分从单一剩余时间改为 `剩余时间 + 少猜奖励`，高分含义更清楚。
- 后续模式先加“经典无限时”，再考虑 Mastermind，不要一步做太复杂。

## 优先级

- P0：中文化热度提示；补桌面键盘输入。
- P1：抽规则函数并补热度边界测试。
- P2：增加经典模式/拆弹模式切换、成功动画和短音效。

## 验证建议

- 单测覆盖 0、5、15、30 这些热度边界。
- 页面测试覆盖数字键、删除、提交、超范围输入和胜利高分。
