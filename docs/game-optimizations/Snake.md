# 贪吃蛇 (Snake) 重制优化计划

## 1. 当前现状与痛点
- **视觉**：使用 Canvas 和 `fillRect` 绘制纯绿色的蛇身和纯红色的食物，风格十分古老，没有网格线或背景层次。
- **尺寸控制**：固定画布 400x400，移动端极不友好，也没有触摸手势。
- **操作反馈**：死亡、吃食物均缺乏强烈的表现。

## 2. 视觉与动效升级 (Juice & Polish)
- **流光赛博朋克风** / **精致像素风**：
  - 如果走像素风，将蛇身替换为带圆角的格子，蛇头增加两个可随方向转动的“眼睛”。
  - 如果走霓虹风，使用 Canvas的 `shadowBlur` 为蛇身添加发光效果（Glow），身体呈现从头到尾的颜色渐变。
- **粒子炸裂效果 (Particle Burst)**：吃掉食物的瞬间，在食物坐标向四周散射十几个逐渐消失的粒子。
- **死亡震动 (Screen Shake)**：撞墙或咬到自己时，触发 CSS 的 `@keyframes shake`，整个游戏画布剧烈震动 300ms，并且整个背景闪红。
- **响应式 Canvas**：基于外层容器大小，自动计算 `W` 和 `H`，并且通过 CSS 维持纵横比，不再硬编码宽高。

## 3. 听觉与反馈体验
- **拾取音效**：轻快短促的“咬一口”（Bite）或电子音（Coin pickup）。
- **死亡重音**：失败时播放较为沉闷或夸张的低音效，配合屏幕震动。

## 4. 机制与周边创新
- **手势支持**：引入类似于 `react-use-gesture` 的滑动监听，使得在手机上可以通过划屏来控制方向。
- **动态食物与增益道具**：
  - 红色食物：常规，+1 长度，+10 分。
  - 金色食物（几率出现，存在 5 秒后消失）：+5 长度，+50 分，且吃掉时全屏特效更强。
- **速度衰减或渐进式加速**：目前固定 `setInterval(loop, 150)`，建议分数越高，速度上限逐步降低，提升后期压迫感。

## 5. 代码重构指引
1. 废弃或重构直接耦合在 `useEffect` 内部的 `tick` 循环。
2. 引入 `requestAnimationFrame` 控制渲染帧率，脱离对 `setInterval` 固定帧的依赖，确保在不同刷新率的屏幕上表现平滑。
