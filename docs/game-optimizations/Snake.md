# 贪吃蛇优化评估

## 源码入口

- 页面：`src/pages/GameSnake.tsx`
- 样式：`src/pages/snake.css`
- 规则辅助：`src/lib/snake.ts`

## 当前状态

当前版本已经有赛博风格网格、粒子、金色食物、死亡震动、响应式画布、虚拟方向键和高分。近期已修复自撞误判：不增长时移动到本回合离开的尾巴格是合法的。

## 已落地优化

- `hitsSnakeBody` 抽出为可测试规则函数。
- 金色食物有 3 秒倒计时和额外长度/分数。
- 分数越高速度越快。
- 高分接入 `useGameStore`。
- 移动端虚拟方向键可玩。

## 待优化问题

- 主循环仍在组件 `useEffect` 内，规则、绘制和 React 状态更新耦合。
- `score/status` 变化会让 RAF effect 重建，能跑但不是最稳的游戏循环结构。
- 食物生成依赖全局 `Math.random`，规则复现和测试不方便。
- 没有暂停、划屏手势、可选边界穿越模式。
- 金色食物过期后调用 `placeFood`，仍有概率再次生成金色食物，规则意图需要明确。

## 建议重构

- 抽出 `stepSnake(state, input, dt, rng)`，页面只负责把键盘/手柄转成 input。
- 规则状态只存网格数据，粒子和绘制状态放渲染层。
- 输入使用方向队列，避免同一 tick 内多次方向覆盖。
- 明确金色食物规则：过期后强制普通食物，还是允许继续随机。

## 优先级

- P0：保留并扩展自撞规则测试；补金色食物过期规则测试。
- P1：抽出纯 step 函数，降低组件复杂度。
- P2：增加划屏、暂停、音效和更细腻的蛇头/身体绘制。

## 验证建议

- 单测覆盖撞墙、撞身体、移动到尾巴、吃普通食物、吃金色食物。
- 浏览器验证移动端方向输入、死亡后重开和高分更新。
