# 2048 重制优化计划

## 1. 当前现状与痛点
- **视觉**：目前依靠简单的 CSS Grid 和纯色块来区分数字，没有合并与滑动的过渡效果。
- **操作**：方块的出现和移动是瞬间完成的（Instant State Swap），缺乏物理滑动感。
- **架构**：矩阵逻辑、合并算法和 React 渲染完全耦合在单页面文件中。

## 2. 视觉与动效升级 (Juice & Polish)
- **绝对定位与平滑滑动**：将现有的 Grid 布局改为绝对定位（Absolute Positioning）。使用 `transition: transform 150ms ease-in-out` 让方块在移动时具备平滑的滑动轨迹。
- **新方块的入场动画**：新生成的数字（2或4）需要从极小（`scale(0)`）通过弹簧动画（Spring）缩放至正常大小，强调“诞生”感。
- **合并冲击波 (Merge Pop)**：当两个数字合并时，触发一个短暂的 `scale(1.2)` 然后迅速回弹的动画，同时背景色有一个极快的高光闪过（Flash）。
- **3D 拟物材质**：舍弃扁平纯色，使用内阴影（Inset Shadow）与微弱的外发光，让方块看起来像“糖果”或“果冻”材质。

## 3. 听觉与反馈体验
- **滑动音效**：每次有效操作伴随轻巧的 "Swish" 声。
- **合并音效**：合并出 8、16、32 等低阶数字时发清脆的 "Pop" 声。
- **高光音效**：合并出 512、1024、2048 时，增加具有成就感、回声较长的高亮音效（并触发屏幕轻微抖动）。

## 4. 机制与周边创新
- **Combo 连击系统**：记录玩家一次滑动造成的连锁合并次数，如果达到连续合并，屏幕右侧飘出 "+X Combo!" 艺术字，增加额外得分。
- **撤销机制 (Undo)**：利用历史栈存储最近 5 步的 Grid 状态，提供有限次数的撤销功能，提升容错率与黏性。

## 5. 代码重构指引
1. **抽离 `use2048Engine`**：将 `moveGrid`、`slideAndMerge`、历史栈记录全部移动至独立的 Custom Hook 中。
2. **定义 `Tile` 唯一 ID**：目前的合并基于数据覆盖，为了动画追踪，必须给每一个 Tile 生成 `id`，在合并时保留即将消失的 Tile，通过 CSS 完成合并动画后再销毁。
