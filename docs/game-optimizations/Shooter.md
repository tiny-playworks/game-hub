# 飞机大战优化评估

## 源码入口

- 页面：`src/pages/GameShooter.tsx`

## 当前状态

当前版本是轻量 Canvas 射击游戏，有玩家飞机、子弹、敌机、得分、重新开始和移动端虚拟手柄。画布已做响应式宽度，手机上不会横向裁切。

## 已落地优化

- 支持方向键、空格和虚拟手柄。
- 虚拟手柄支持按下/松开，长按移动和长按开火能工作。
- 点击画布或按开火可从 idle 开始。
- 基础敌机生成、碰撞和得分闭环完整。

## 待优化问题

- 没有生命、护盾或受击缓冲，碰撞直接结束，容错偏低。
- 敌机只从顶部随机直线下落，模式单一。
- 循环按帧计数，没有基于 dt，低帧率下速度和生成节奏会变化。
- 子弹、敌机、爆炸事件都在组件里直接数组过滤，没有对象池或事件层。
- 未接入 `useGameStore` 高分、击落数、游玩统计。
- 没有暂停、失败后快捷再来一局、移动端开火说明。

## 建议重构

- 抽出 `src/lib/shooter.ts`，用 `stepShooter(state, input, dt, rng)` 驱动规则。
- 定义实体类型：player、bullet、enemy、particle，并用事件返回 `enemy_destroyed`、`player_hit`。
- 先加 3 类敌机：直线、斜线、慢速高分，不急着做 Boss。
- 引入生命值和短暂无敌时间，提升普通玩家可玩性。

## 优先级

- P0：接入高分统计；加暂停/失败后再来一局入口。
- P1：改为 dt 驱动并抽规则函数；补敌机命中和玩家受击测试。
- P2：加入爆炸粒子、星空视差、武器升级和敌机编队。

## 验证建议

- 单测覆盖子弹命中、敌机越界、玩家碰撞、发射冷却。
- 浏览器验证移动端长按移动、长按开火和松手停止。
