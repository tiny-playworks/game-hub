# 俄罗斯方块 (Tetris) 重制优化计划

## 1. 当前现状与痛点
- **手感优化**：如果没有完美实现 DAS（延迟自动位移）、ARR（自动重复率）和硬降/软降（Hard/Soft Drop）的物理反馈，硬核玩家会觉得手感很黏。
- **视觉枯燥**：方块可能只是简单的纯色块。

## 2. 视觉与动效升级 (Juice & Polish)
- **高级渲染材质**：为四格拼板（Tetromino）加上高光边界、内阴影，使其更具“晶体”或“金属”质感。
- **硬降下坠光晕 (Ghost & Drop Trail)**：
  - 常驻显示底部落点的 **Ghost Piece（幽灵方块）**（半透明边框），方便瞄准。
  - 按下空格执行 Hard Drop 时，方块下砸的轨迹留下一道光柱残影，并激起底部的几粒灰尘粒子。
- **消行动画**：行消除时，不应立刻消失，而是从中间向两侧闪白并向外碎裂弹出，紧接着上方砖块带有缓动动画（Tween）掉落填补空隙。

## 3. 听觉与反馈体验
- 方块平移、旋转、软降时的微小机械声（Click）。
- **四行连消 (Tetris!)** 触发极度清脆和震撼的爆破声效，配合明显的屏幕震动，甚至播报语音。
- **连击系统 (REN/Combo)**：声音的音调随着消行 Combo 次数上升，营造紧张的兴奋感。

## 4. 机制与周边创新
- **Hold 机制**：允许按 `C` 键将当前方块暂存（Hold），增加策略深度。
- **SRS (Super Rotation System) 踢墙系统**：这是现代俄罗斯方块的灵魂。让方块在靠近边界或其他方块旋转时，根据特定的碰撞表自动偏移一个格子，允许玩家进行高难度操作（如 T-Spin）。
- **T-Spin 判定**：加入 T 旋检测，给予额外特效和高分奖励。

## 5. 代码重构指引
- 将核心逻辑抽离为纯粹的状态机：`nextPieces`, `holdPiece`, `matrix`, `currentPiece`。
- 严格遵循 SRS 和国际 Tetris 准则设计方块颜色的对应和旋转矩阵补偿。
- 物理渲染层（Canvas 或 React Grid）仅作为只读消费者获取 state，不再负责计算业务逻辑。
