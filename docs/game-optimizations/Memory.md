# 记忆翻牌 (Memory) 重制优化计划

## 1. 当前现状与痛点
- **表现平淡**：翻牌通常只是粗暴的替换图片或背景色，没有实际的“翻转”感觉。
- **反馈缺失**：配对成功或失败后，等待的过程枯燥。

## 2. 视觉与动效升级 (Juice & Polish)
- **真实的 3D 翻牌**：利用 CSS 的 `perspective`, `transform: rotateY(180deg)` 和 `backface-visibility: hidden` 属性，实现完美立体的扑克牌翻转动画。
- **牌面设计**：
  - 卡背采用复杂的花纹图案（甚至可以加上细微的金箔闪光 Hover 特效）。
  - 卡面可以是精美的游戏内角色、麻将牌或其他特色图元。
- **配对反馈**：
  - **成功**：两张牌边缘泛起绿色光晕，向上浮起，然后化作粒子消散，或收入特定的完成槽位中。
  - **失败**：两张牌短暂变红并伴随轻微的左右抖动（Shake），然后自动反向翻转盖回去。

## 3. 听觉与反馈体验
- 纸牌翻动的清脆物理声（Swish）。
- 配对成功时的轻铃声（Ding!），配对失败时的低沉错误提示音（Buzzer）。

## 4. 机制与周边创新
- **时间攻击模式 (Time Attack)**：除了最基础的不限时记忆，加入倒计时。连续配对成功增加剩余时间，增加紧张感。
- **干扰系统**：在困难模式下，一段时间未翻完，已翻开的几对未知卡牌会“洗牌”（在棋盘上飞来飞去互换位置），极大考验瞬间记忆力和专注力。
- **多层解谜**：使用类似《羊了个羊》或《麻将连连看》的堆叠结构。

## 5. 代码重构指引
- 状态极简化：`cards` 数组包含所有卡片的 `id, type, isFlipped, isMatched`。
- 使用统一的 `useTimeout` 或自定义 Hook 管理“翻两张后停留1秒再翻回”的异步时序问题，防止在此期间玩家疯狂乱点导致状态错乱。
