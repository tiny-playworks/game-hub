# 坦克大战 (Tank) 重制优化计划

## 1. 当前现状与痛点
- **移动僵硬**：坦克只能沿着绝对网格对齐走，缺乏现代双摇杆射击的灵活度；或者即便能自由移动，但动画只有生硬的转身。
- **打击感缺失**：炮弹击中墙体或敌方坦克没有物理上的反馈。

## 2. 视觉与动效升级 (Juice & Polish)
- **履带印记**：坦克行驶过的地方，在地上留下随着时间渐渐淡出的两道履带痕迹（Trail）。
- **开火后坐力 (Recoil)**：炮塔开火瞬间，坦克车体向反方向有一个瞬间的位移震动。
- **动态光照与阴影**：为坦克的炮弹增加点光源，当炮弹飞行穿过屏幕时，照亮周围的墙壁边缘。
- **像素/硬派机甲美术强化**：利用 Sprite sheet 取代基础形状，为坦克的炮塔旋转和底座移动增加独立图层，允许“边走边朝侧面开火”。

## 3. 听觉与反馈体验
- 沉重的引擎怠速声与行驶履带声。
- 炮弹打中铁墙的“叮当”跳弹声，打中砖墙的“粉碎”声。

## 4. 机制与周边创新
- **双摇杆射击 (Twin-stick shooter)** 模式，WASD 移动，鼠标控制炮塔瞄准方向，点击开火。这将彻底改变传统红白机坦克大战的体验。
- **地形与破坏系统**：不仅保留能打穿的红砖、打不穿的铁砖，新增“草丛”（隐蔽自己）、“冰面”（滑动失控）、“水面”（无法通过但炮弹能过）。
- **多种炮弹类型**：散弹、穿甲弹（打透一排敌人）、榴弹（抛物线越过墙壁）。

## 5. 代码重构指引
- 将坦克的 `Hull` (车体) 和 `Turret` (炮塔) 解耦渲染。
- 构建一个高效的 2D 瓦片地图 (Tilemap) 管理系统，所有的寻路、碰撞墙体检测都依赖这个二维数组或栅格系统，而炮弹的碰撞采用基于光线投射 (Raycast) 的精密检测。
