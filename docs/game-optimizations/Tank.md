# 坦克大战优化评估

## 源码入口

- 页面：`src/pages/GameTank.tsx`

## 当前状态

当前版本是单文件 Canvas 坦克游戏，有 13x13 地图、玩家坦克、敌方坦克、子弹、基地、胜利/失败状态和移动端虚拟手柄。手机画布已不再裁切。

## 已落地优化

- 支持方向键、空格和虚拟手柄。
- 地图有砖墙和基地，子弹能破坏砖墙。
- 敌人会生成、移动、开火。
- 玩家目标明确：保护黄色基地并消灭敌人。

## 待优化问题

- 地图、AI、碰撞、渲染全部在页面组件里，单文件已经接近维护上限。
- 敌人 AI 基本是随机转向和随机开火，挑战不稳定。
- 没有高分、关卡、剩余敌人数 HUD 和成长系统统计。
- 子弹和坦克碰撞是简化矩形逻辑，边界手感和地图贴合度还可以提升。
- tile 类型已经有 `2` 的分支，但模板里主要只用了砖墙和基地，地形系统还没发挥作用。

## 建议重构

- 抽出 `src/lib/tank.ts`：地图查询、坦克移动、子弹步进、碰撞事件。
- 地图用可读配置表示：空地、砖墙、铁墙、基地、出生点。
- AI 先做简单目标导向：优先朝基地或玩家方向移动，而不是纯随机。
- HUD 显示剩余敌人、基地状态、玩家生命。

## 优先级

- P0：接入高分/通关统计；显示剩余敌人数。
- P1：抽地图和碰撞规则，补子弹打墙/打坦克/打基地测试。
- P2：增加铁墙、草丛、爆炸、履带痕迹和关卡配置。

## 验证建议

- 单测覆盖四方向移动阻挡、砖墙破坏、基地被击中、清空敌人胜利。
- 浏览器验证虚拟手柄方向松开、开火松开和移动端画布尺寸。
