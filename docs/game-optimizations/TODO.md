## 交给后续助手的注意事项

- 先读源码再判断，不要根据旧文档或印象写结论。
- 不要把已经完成的能力写成待办。
- 优先可玩性、一致性、移动端、统计和规则测试，不要过度设计。
- 改 UI 文案要同步改测试锚点。
- 中文站点优先中文文案。
- Canvas/3D 用桌面和约 390px 视口各看一遍。
- 随机逻辑优先可注入 RNG。
- 统计优先用现有 `useGameStore`。
- 做完至少跑 `pnpm run typecheck` 和相关 `rstest`。
