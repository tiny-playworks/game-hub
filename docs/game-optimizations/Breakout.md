# 打砖块 (Breakout) 重制优化计划

## 1. 当前现状与痛点
- **视觉**：基于基础几何体的矩形砖块与小球，碰撞效果生硬。
- **表现力**：砖块消失瞬间没有碎裂感，缺乏“破坏”带来的爽快感。
- **游戏感**：球的反弹路径完全依赖物理坐标，缺乏对于拍子（Paddle）打出“弧线球”的控制感。

## 2. 视觉与动效升级 (Juice & Polish)
- **碎片飞溅特效**：采用类似于“玻璃碎裂”的视觉呈现。当球击中砖块时，利用 Canvas 绘制几个多边形碎片向下坠落并淡出，极大增强打击感。
- **球的拖尾 (Trail)**：给运动中的小球加上透明度渐变的拖尾（保存最近 5 帧的坐标并用降低透明度的圆形连成线），增加速度感。
- **动态撞击变形 (Squash & Stretch)**：小球在撞击墙壁或挡板的瞬间，变成稍扁的椭圆（根据运动方向变形），模拟弹性的物理状态。
- **多图层视差背景**：用暗星空或赛博朋克深色背景替代纯色，甚至可以让砖块带有呼吸灯效果。

## 3. 听觉与反馈体验
- **音阶反馈**：连击同一个或连续消灭多个砖块时，音效的音高（Pitch）逐渐升高，制造极强的正向反馈循环。
- **重击震屏**：打中特定的坚硬砖块（需多次打击）或过关时震动屏幕。

## 4. 机制与周边创新
- **多重掉落物 (Power-ups)**：
  - 变长/变短挡板
  - 激光枪：挡板暂时获得射击能力，击碎上方砖块
  - 多重球 (Multi-ball)：小球一分为三
- **触屏跟随**：允许移动端手指直接在下方滑动，挡板实时跟随手指 X 轴，大大降低手机游玩门槛。
- **连击计分仪**：球未落到挡板上，在空中连续弹射破坏的砖块数计为 Combo，分数呈指数级增长。

## 5. 代码重构指引
- 将 `update` 与 `draw` 严格剥离。
- 采用面向对象或实体组件系统 (ECS) 管理各种实体的状态，比如 `class Ball`, `class Paddle`, `class Brick`。
- 剥离出一个独立的碰撞检测模块 `CollisionEngine`，支持 AABB 边界盒与圆的碰撞，以便后期优化边缘反弹判定。
