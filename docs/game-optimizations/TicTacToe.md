# 井字棋 (Tic-Tac-Toe) 重制优化计划

## 1. 当前现状与痛点
- **过于平淡**：几乎所有人的入门项目，3x3 的网格加上 X 和 O，没有任何深度，甚至很容易玩出平局（和棋）。
- **缺乏挑战**：如果只是跟瞎走的 AI 或朋友同屏玩，几分钟就会厌倦。

## 2. 视觉与动效升级 (Juice & Polish)
- **霓虹与描边渲染**：抛弃纯色文本，X 和 O 使用发光的霓虹灯管材质。落下时像电子笔一样拥有绘制动画（SVG `stroke-dasharray` 动画）。
- **胜利连线特效**：决出胜负时，胜利的那条线不仅是被划出来，而是发出一束高强度的激光贯穿屏幕，配合强烈的震屏。
- **落子冲击感**：每次落子，棋盘网格向深处凹陷一下再弹回。

## 3. 听觉与反馈体验
- 电流声（Buzz）代表 X 落子，清脆的水滴/敲击声代表 O 落子。
- 连线成功的雷鸣/电流爆破声。

## 4. 机制与周边创新
- **无限井字棋 (Tic-Tac-Toe Infinite)**：当场上的棋子达到 6 个（每人 3 个）时，再下新子，自己最早下的那颗棋子就会消失！这就把井字棋变成了一个具有深度的动态记忆博弈游戏。
- **嵌套井字棋 (Ultimate Tic-Tac-Toe)**：在大网格的每一个格子里还有一个小井字棋。玩家的落子位置会强迫对手在对应的大格子里落子。这是全球最火的井字棋变种策略。

## 5. 代码重构指引
- 将获胜判定从简单的硬编码数组遍历，升级为支持 `N x N` 或者动态移除旧棋子状态的算法。
- UI 层完全依托于 SVG 绘制，以便精准控制线条的连结和动画时长。
