# 井字棋优化评估

## 源码入口

- 页面：`src/pages/GameTictactoe.tsx`
- 样式：`src/pages/tictactoe.css`

## 当前状态

当前版本已经不是普通 3x3 静态井字棋，而是“无限井字棋”：每方最多保留 3 枚棋子，继续落子会移除最早棋子。页面有霓虹风格、胜利连线、AI 模式和本地双人模式。

## 已落地优化

- 无限井字棋机制已经实现，玩法比传统平局局面更有变化。
- 有 PvE/PvP 切换。
- AI 会先找自己能赢的位置，再尝试阻挡玩家。
- 胜利时有连线动画和震动。

## 待优化问题

- 无限规则只靠视觉淡出提示，玩家第一次进入时不一定理解“最早棋子会消失”。
- 获胜判断和 AI 逻辑仍在页面文件里，缺少纯规则测试。
- AI 最后一步随机，策略强度不稳定，可能出现明显低级走法。
- 标题和模式按钮仍有英文：`INFINITE TAC`、`PvE`、`PvP`。
- 没有比分、轮次记录和先手切换。

## 建议重构

- 抽出 `src/lib/tictactoe.ts`：落子、移除最早棋子、胜负判断、AI 选点。
- AI 分层：先赢、再挡、再优先中心/角、最后随机。
- UI 加一行极短规则提示，不写长教程。
- 增加小比分：X 胜、O 胜、平局/重开次数。

## 优先级

- P0：中文化标题/模式；补规则提示。
- P1：抽规则和 AI，补无限机制测试。
- P2：增加更强 AI、比分、落子音效和连线胜利特效。

## 验证建议

- 单测覆盖每方第 4 子会移除最早子、胜利线、AI 必胜/必挡。
- 页面测试覆盖 PvE/PvP 切换、胜利连线和重开。
