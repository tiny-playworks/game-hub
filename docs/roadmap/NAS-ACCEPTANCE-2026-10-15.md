## 2. 本轮修复

- **成员离线闭环**：缓存最后一次 NAS 确认档案；已加载的自由局断网后本地继续，完赛提交完整牌谱；小游戏离线结果进入队列，奖励待 NAS 确认，不预先修改成员余额。恢复连接自动刷新、同步及上传续局。身份切换和过期请求有成员隔离保护。
- **自由局续玩与防重**：展示服务端活动自由局，显式选择并转移设备归属。离线续接须与 NAS 原始牌谱前缀、种子、规则、设备及成员一致；终局清理续局记录，同一场不同事件 ID 也不能重复发奖。段位局仍须在线。
- **家庭桌可靠性**：补齐 protocol、roomId、matchId、revision、角色与设备校验；指令防重落库，重启后仍生效。旧设备或旁观连接关闭不再错误标记当前控制设备掉线；重连/接管恢复暂停状态。
- **家庭奖励隔离**：新增持久 `family_results`，以成员/牌局防重，家庭基础雀币独立每日上限 200；单人桌和全程未手动操作的托管席不发成长奖励。家庭局不改变 AI 段位和 P16 挑战。
- **私有动作修复**：真实双成员整场发现非行动席收到行动席的 turnOptions。现按本人座位生成选项，非本人回合不下发他人的合法弃牌 ID；回归测试覆盖该情形。
- **连接边界**：WebSocket 同源、会话、载荷大小与连接计数校验；房主设置权限、AI 席位边界和在线段位/家庭活动局互斥补齐。
- **页面与发布可追溯性**：修复大厅巡礼标题被图标尺寸样式挤成竖排；健康接口、容器镜像与静态清单记录代码版本。兼容已有 CommonJS 单机服务的规范检查配置，本轮不生成其 EXE。

## 6. 发布与回退操作约定

Git 推送不会自动部署家庭内网 NAS。当前静态发布入口 `scripts/deploy-to-nas.ps1 -Activate` 只处理静态包；更改 `server/` 或 `shared/` 时必须同时构建 API 镜像并更新正式 Compose，不能把“已推送”写成“已部署”。本轮已实际完成二者，且比对其源码版本。

后续发布顺序：核对活动局与持久卷 → 数据库一致性备份 → 干净提交构建静态清单与带版本的 API 镜像 → 隔离端口验收 → 更新正式 API 并等健康 → 重新加载静态 Nginx 使上游解析生效 → 原子激活静态版本 → 比对 `/release.json`、`/healthz` 及成员数据。每轮另取新 releaseId，不覆盖旧版本目录。

当前仅需静态回退时，可在 NAS 执行：

```sh
sh /volume1/docker/game-hub/nas-release.sh rollback /volume1/docker/game-hub previous http://127.0.0.1:8089
```

整站程序回退还须把 `game-hub-api:pre-closeout-20261015b` 标记回正式 API 别名，再对原 `game-hub-live` Compose 运行 `up -d --no-build game-hub-api`，健康后重载静态容器 Nginx。数据库备份用于确需恢复的故障；不得无条件覆盖发布后新增的用户进度。QA 已验证静态手动及失败回退，正式发布期间没有为了演练而回退用户站点。
