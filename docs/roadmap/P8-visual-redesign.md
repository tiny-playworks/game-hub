## 验收：本机

1. 主要页面设计确认后再编码；对照概念和浏览器截图验收。
2. 所有既有导航、购买、角色切换、语言切换可操作。
3. 电脑/手机主要牌桌没有裁切手牌、遮住鸣牌按钮或全页面水平滚动。
4. 旧存档和已购外观保留；16 个副玩法公共顶栏仍可暂停与设置。
