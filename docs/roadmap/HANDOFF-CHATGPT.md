## 有 NAS 的接手方

通过 `synology-nas` 操作。项目根 `/volume1/docker/game-hub`，正式 Compose 在 `source/deploy/nas/compose.yml`，项目名 `game-hub-live`，数据目录 `data/`。备份与回退步骤见验收记录，不得用旧库无条件覆盖用户新进度，也不要改动其他媒体容器。

Git 推送不会自动部署内网 NAS。静态发布脚本只更新静态；如果改了 API/共享契约，需同步构建并切换 API、等待健康、重载静态 Nginx，再激活静态包，最终比对两端代码版本。本轮已完成完整发布。
