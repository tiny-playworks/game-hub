## 26.1 引擎改造

- 增加座位参数化版本（如 `canPlayForSeat(state, seat, cards)`、`isTurnOf(state, seat)`）；旧 API 保留为 `seat = 1` 的兼容封装，单人页面行为不变。
- 新增叫分阶段：发牌后从随机首叫者起依次叫 1 / 2 / 3 分或不叫；叫 3 分立即成为地主；一轮结束取最高者；三人都不叫则重发。地主拿底牌，底牌对全桌公开。
- AI 叫分按手牌强度（炸弹、王、大牌数量等）决策，档位沿用单人。
- 单人 vs AI：默认保持随机地主；可在设置中开启叫分。

## 26.2 对战规则

- 3 席，1–3 真人，空位 AI 补齐；至少 2 名真人完赛才发奖与计对线表。
- `timeoutPolicy = 'autoplay-after-grace'`：每步限时（房主可选档位，默认沿用日麻家庭桌口径），超时执行默认操作（能不出则不出，必须出时出最小合法牌）；掉线 **60 秒**宽限后 AI 托管，重连在下一决策点接回；全真人离线则暂停。与 P13 口径一致。
- 一局为一手牌；结束后“再来一局”保留座位，首叫者轮换。
- 结算：地主方 / 农民方胜负计入各成员胜负；春天/炸弹倍数用于展示，奖励仍按街机单局公式（不按倍数放大），`family-arcade` 来源，与家庭日麻共享每日 200 上限。全程未自行操作的托管席只记战绩不发奖励。
- 对线表：两名成员同桌一局时，各自记胜/负（同为农民同胜同负也计入）；展示时区分“同队 / 对家”。

## 26.3 隐藏信息投影

- 本人视角只含：自己手牌、他家剩余张数、已出牌、底牌（定地主后）、叫分记录、当前轮到谁与本人合法操作。
- 不下发：他人手牌、未发底牌（定地主前）、牌堆 seed、AI 内部评估。
- 完整牌局记录仅终局后对参赛成员开放（如做回放）。
- 不支持观战（需要公共视角与防场外报牌，见“不做”）。

## 验收

1. 三台设备三名成员 / 两名成员 + AI 各完成一局：叫分、重发、定地主、出牌、春天、炸弹、结算全部正确。
2. 抓包或检查 WS 消息：任何时刻都拿不到他人手牌与定地主前的底牌。
3. 超时默认操作、60 秒托管、重连接回、全员离线暂停、服务重启恢复均通过且不重复结算。
4. 单人斗地主（默认随机地主）行为与改造前一致；开启叫分后可正常进行。
5. 1 真人 + 2 AI 不发奖、不计对线表；共享每日上限生效。
6. 手机横屏/竖屏可完整选牌出牌（选牌防误触、按钮 44px 触控区）；中英文、浅/深色截图核对；NAS 现场记录另做。

## 不做

- 不做抢地主 / 加倍 / 明牌等地方规则，不做斗地主观战，不做升级对战。

## 2026-10-20 本地实现与证据

- `doudizhu.ts` 增加任意座位的回合、出牌、不出和 AI 接口，以及独立叫分状态与 AI 叫分。原单人 API 继续以 1 号位为玩家，默认仍随机地主；设置中可开启叫分，底牌在定地主后显示。
- 新增斗地主适配器；本人投影只包含自己手牌、其余成员张数、出牌、公开底牌与叫分记录。未定地主时底牌为空，不返回其余手牌、seed 或 AI 内部状态，且拒绝观战。
- 服务端每步默认 15 秒（可选 10/15/30 秒）；超时默认不叫/不出，必须领出时出最小单张。掉线 60 秒后托管，重连在下一决策点接回；全真人离线暂停。春天/炸弹倍数只用于展示，不放大奖励。
- 对线表按成员自己的胜负落盘，并区分同队/对家；至少两名未主动退出真人完赛才记录，全程没有自行操作的席位不发奖励。奖励来源、幂等与家庭每日 200 上限沿用 P24。
- 本机三名临时成员入座、准备，已观察全不叫后重新发牌、叫 3 分立即成为地主、底牌公开及超时默认操作。成员视角返回本人 17/20 张手牌及全桌张数，没有他人手牌或未公开底牌；已通过实际页面继续出牌。
- 本局在第 74 个动作后地主胜出，三名成员分别到账 20 / 5 / 5 雀币；炸弹展示倍数为 ×8，奖励没有按倍数放大。对线表同时写入农民同队、地主/农民对家的关系。
- 实际 `/ws` 终局帧仅有当前成员的 4 张手牌及 `[0, 4, 3]` 的全桌张数，没有全量 `hands`、seed 或 AI 内部状态；这次抓包没有覆盖全部中间帧。单人游客页面另核对默认随机地主，以及开启叫分后叫 3 分拿底牌并正常出牌。
