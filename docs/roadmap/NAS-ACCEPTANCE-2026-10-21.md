## 本轮修复与工程验证

- `migrate-check` 改用 SQLite 的一致性快照，包含已提交的 WAL 内容；不再分别复制数据库、WAL 和 SHM，以免在线写入时混入不同代的数据。
- 修复大厅精选复盘推荐的成员隔离：更换成员后按新身份重新查询；请求结果带所属身份，旧请求不能给新成员留下推荐；离线时隐藏在线牌谱推荐。推荐列表直接从当前进度派生。
- Compose 支持固定 `GAME_HUB_API_IMAGE`，并把 `GAME_HUB_REVISION` 传入镜像构建，便于前后端版本核对和明确回退。
- 新增 14 项通用房间回归，覆盖合法整局、防重/冲突、控制权、暂停/作废、恢复、家庭共享上限、观战、协商、计时、暗牌、单真人不发奖、整场未操作真人席不发奖、托管与再战；新增 2 项精选成员切换/离线回归，两项在修复前均复现失败。

最终程序与补充测试通过三份类型检查、432 个文件的静态检查、**89 套件 / 633 项测试**、前后端构建及 `git diff --check`。前端最终发布包为 `nas-full-20261021b`；V2 精选配置的单独试验包只用于隔离站，正式包仍使用 V1。NAS 镜像内的 Node 街机结算门禁和日麻规则门禁也已运行成功。

## 页面与交互

使用已提供的 Playwright + Edge；本会话未提供 Browser 插件/对应技能，未安装浏览器依赖。最终版完成 27 个桌面路由及 13 个手机路由，共 40 个页面场景；另检查三种尺寸下的三种真人游戏结果页，共 9 个场景，以及三种尺寸的真实历史榜 → 周榜交互。未发现相关页面异常、失败静态资源或整页横向溢出。

逐图检查了首页、家庭大厅、真实榜单、真人斗地主结果和巡礼实际牌桌。巡礼从列表点击开始进入实际手牌；浅色中文、深色英文、桌面 1440×900、竖屏 390×844、横屏 844×390 有截图。页面核对等待路由实际加载完成，未把加载占位截图算作最终页面证据。

正式站另用无正式成员会话的独立浏览器完成 8 路由 × 桌面/手机共 16 个场景，无页面异常或横向溢出。正式站 242 个清单文件均逐个下载并核对散列，六条深链、WASM MIME、哈希资源 immutable、服务脚本 no-cache、未登录 API 的 401 及旧 `index.3185d9ad0c.js` 保留通过。Jellyfin 200、FreshRSS 302、家庭首页 200，其他原有容器仍保持原先运行状态；本轮未操作媒体文件。

## 发布、回退与设备边界

- 正式切换先做最新一致性备份及迁移演练，再使用固定镜像更新 API，等健康后更新 Nginx、原子激活静态指针。发布程序失败时恢复上一 API / 静态配置，保留数据库，不自动覆盖用户新进度。
- QA 已完成静态手动回滚、不可达健康地址触发自动回退并释放锁；旧 `fe79089` API 也从新 QA 数据副本成功启动。该测试不是允许无条件用旧数据库覆盖正式库的授权。

- 最终正式容器均为 healthy，Compose 来源固定在 `builds/nas-full-20261021b/deploy/nas/compose.yml`，不依赖 QA 配置。静态目录及 Nginx 配置只读挂载，API 保持原 `/data` 持久目录。已关闭隔离站，HTTP 18089 不再可达；数据库、日志、所选 JSON 与截图归档在 QA 的 `evidence/`。正式 8089 保持健康。
