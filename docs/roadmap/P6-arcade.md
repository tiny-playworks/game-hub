## 6.1 GameShell 统一

现状：围棋/象棋/国际象棋/五子棋/斗地主/升级已用 `GameShell`；猜数字、井字棋、记忆翻牌、2048、贪吃蛇、打砖块、飞机大战、坦克大战、俄罗斯方块、魔方未用。

`GameShell` 增强：

结算统一用 `GameResultOverlay`，新增 `isNewBest` 时显示金色「新纪录！」徽章与旧纪录对比。

## 6.3 个人最佳

- `gameStore` 的统计 key 改为 `${gameId}:${difficulty}`，并兼容迁移旧 key（旧数据归入默认难度）。
- 每个游戏定义「最佳」语义：

| 类型         | 游戏                                                 | 最佳 =            |
| ------------ | ---------------------------------------------------- | ----------------- |
| 分数越高越好 | 2048、贪吃蛇、打砖块、飞机大战、坦克大战、俄罗斯方块 | 最高分            |
| 越少越好     | 猜数字（次数）、记忆翻牌（步数）、魔方（用时）       | 最小值            |
| 胜场         | 井字棋、四种棋、斗地主、升级                         | 胜场数 + 最高连胜 |

- 在 `src/data/games.ts` 的 `GameItem` 上加 `bestMetric: 'max' | 'min' | 'wins'` 与 `bestUnitKey`。
- 大厅街机角与分类页卡片显示个人最佳徽章（当前默认难度）。

## 6.4 接入事件总线

每个游戏在合适时机调用 P1 的 `emitGameEvent`：

- `start`：开始一局（由 GameShell 统一上报，避免重复）；
- `finish`：一局结束（含失败）；
- `win`：获胜/完成（棋牌胜、魔方复原、猜中、翻完、打砖块清版等）；
- `best`：刷新个人最佳。

现有散落的 `unlock(...)` 调用迁移为由事件驱动的成就检查（`achievements.ts` 根据事件与统计判定），游戏页面不再直接调用 `unlock`。

## 6.5 雀币（副玩法）

| 事件   | 雀币              |
| ------ | ----------------- |
| finish | 5                 |
| win    | 15（困难难度 ×2） |
| best   | 20                |

- 副玩法每日雀币上限 **200**（`wallet.dailyArcadeEarned`），达到后结算页提示「今日街机奖励已满」。保证日麻仍是主要来源。

## 6.6 任务池扩展

- 每日任务 3 条改为：**2 条日麻 + 1 条街机**；每周任务增加 1 条街机。
- 任务事件类型从日麻专属扩展为通用：`{ scope: 'riichi', event } | { scope: 'arcade', gameId?: string; category?: CategoryId; type: GameEventType }`。
- 街机任务示例（每日随机 1 条）：
  - 在任意小游戏中刷新一次个人最佳；
  - 完成 3 局棋类对局；
  - 赢下 1 局斗地主或升级；
  - 2048 达到 512；
  - 俄罗斯方块消除 20 行；
  - 魔方在 12 步打乱下复原 1 次。
- 每周街机示例：赢下 5 局棋类 / 在 3 个不同小游戏中刷新纪录。

## 6.7 成就扩充

每个副玩法 3–5 个成就（保留现有 14 个 id 不变），总计约 60 个。示例：

| 游戏                     | 新增成就示例                            |
| ------------------------ | --------------------------------------- |
| 猜数字                   | 7 次内猜中 1–100；1–1000 一次性 10 次内 |
| 井字棋                   | 战胜普通 AI；与不败 AI 连续 5 次和棋    |
| 记忆翻牌                 | 6×6 完成；4×4 零失误                    |
| 打砖块                   | 困难通关；不丢球通关                    |
| 飞机大战                 | 单局击落 100；困难存活 3 分钟           |
| 坦克大战                 | 首胜；基地零损伤通关                    |
| 魔方                     | 首次复原；25 步打乱 3 分钟内复原        |
| 围棋                     | 首胜；战胜困难 AI                       |
| 象棋 / 国际象棋 / 五子棋 | 战胜困难 AI；30 手内获胜                |
| 斗地主                   | 首胜；打出春天；作为地主连胜 3 局       |
| 升级                     | 首胜；一局升 2 级以上                   |

- 成就页按「日麻 / 小游戏 / 棋类 / 扑克」分组，每组显示完成度；每个游戏卡可展开看该游戏成就。
- 稀有度与成长点沿用现有体系。

## 验收

1. 16 个副玩法全部使用统一顶栏，均可暂停（实时类失焦自动暂停）、在齿轮里切难度。
2. 每个游戏结束都有统一结算弹层；刷新纪录时显示「新纪录！」与旧纪录。
3. 大厅与分类页卡片显示个人最佳；切换难度后最佳独立记录。
4. 玩副玩法能获得雀币，当日累计到 200 后不再增加并有提示。
5. 每日任务中有 1 条街机任务，完成后可领取；成就页按分组显示约 60 个副玩法成就。
6. 老存档的 2048/贪吃蛇/俄罗斯方块最高分在默认难度下保留，已解锁成就不丢失。

## 不做

- 不新增游戏（含麻将接龙等候选）。
- 不做小游戏排行榜、联机。
- 不重做小游戏核心玩法与美术（只统一外壳 + 难度 + 结算）。
