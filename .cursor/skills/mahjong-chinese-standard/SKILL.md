# 中国通用麻将规则技能

本技能提供中国通用麻将（非地方变种）的完整规则知识，供实现、判定、计分时严格遵循。

## 何时使用

- 实现或修改麻将发牌、行牌、吃碰杠胡逻辑时
- 编写或调试胡牌判定（基础型与特殊牌型）时
- 实现番种与计分（含杠牌单独计分）时
- 处理流局、过轮、漏碰/漏吃/漏胡时
- 需要统一术语或判定优先级时

## 核心要点速查

| 模块 | 要点 |
|------|------|
| **牌具** | 136 张无花牌：万/条/筒各 36 张（1–9 各 4 张），字牌 28 张（东南西北中发白各 4 张） |
| **人数与目标** | 4 人，东/南/西/北固定方位；庄家 14 张先出，其余 13 张；先胡牌者胜 |
| **术语** | 手牌、牌池、牌墙、面子（顺子/刻子）、将牌、杠牌（明杠/暗杠/补杠）、听牌、胡牌、番种、流局、诈胡 |
| **定庄** | 随机定庄或上局胡牌者坐庄；流局则庄家连庄 |
| **行牌** | 摸牌→可选吃/碰/杠→打牌；杠后从牌墙**末尾**补 1 张再打 1 张 |
| **优先级** | 杠 > 碰 > 吃；胡牌优先于杠/碰/吃；过轮后不可再要该张牌 |
| **吃** | 仅上家；序数牌组成顺子；字牌不可吃 |
| **碰** | 任意一家；手中 2 张 + 打出 1 张 = 明刻 |
| **杠** | 明杠（他人打第 4 张 / 补杠）、暗杠（手中 4 张）；杠后必补牌再打牌 |
| **胡牌** | 14 张；基础型 = 4 面子 + 1 对将；特殊型 = 七小对(4番)/龙七对(6番)/十三幺(8番) |
| **番种** | 屁胡1、自摸1、杠上开花1、海底捞月1、门清1、对对胡2、混一色2、清一色4、七小对4、龙七对6、十三幺8；可叠加 |
| **计分** | 最终得分 = 基础分×总番数；自摸 3 家付，点炮仅点炮者付；杠牌单独计分（明杠点杠者付 1 倍，暗杠 3 家各付 1 倍） |
| **流局** | 牌墙摸完无人胡；杠牌分照算；庄家可连庄 |
| **易错** | 字牌不可组顺子；吃仅上家；杠后必补牌再打牌；胡牌与杠牌计分分开 |

## 判定优先级（必须严格遵循）

1. **要牌阶段**：胡 > 杠 > 碰 > 吃；同优先级下按逆时针最先报者有效。
2. **过轮**：未在要牌阶段报出，下家开始操作后，本局不可再碰/吃/胡该张牌。

## 实现检查清单

实现或修改麻将逻辑时，可逐项核对：

- [ ] 发牌：庄家 14 张，其余 13 张；庄家先出牌
- [ ] 吃：仅上家、序数牌顺子、过轮无效
- [ ] 碰/明杠/暗杠/补杠：优先级与补牌（从牌墙末尾）正确
- [ ] 胡牌：基础型 4 面子+1 将，特殊型七小对/龙七对/十三幺
- [ ] 番种：门清（无吃碰明杠）、自摸、杠上开花、海底捞月、对对胡、混一色、清一色等正确叠加
- [ ] 计分：自摸 3 家付、点炮 1 家付；杠牌单独结算
- [ ] 流局：牌墙摸完无人胡，杠分照算
