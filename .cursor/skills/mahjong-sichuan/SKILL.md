# 四川麻将规则技能

本技能提供四川麻将的规则要点，供实现、判定、计分时参考。

## 何时使用

- 实现或修改四川麻将发牌、定缺、行牌、吃碰杠胡逻辑时
- 编写或调试胡牌判定（基础型与七对系列）时
- 实现番型与计分时
- 处理血战到底、刮风下雨等特色规则时

## 核心要点速查

| 模块 | 要点 |
|------|------|
| **牌具** | 136 张：万/条/筒各 36 张，字牌 28 张，与国标相同 |
| **定缺** | 开局前每人选择缺门花色，本局手牌中不能有该花色才能胡牌 |
| **血战到底** | 一家胡牌后其他人继续打，直到牌墙摸完或三家都胡 |
| **刮风下雨** | 杠牌即时计分：暗杠 2 分、明杠/加杠 1 分 |
| **吃碰杠** | 吃仅上家；碰、明杠、暗杠、加杠与国标类似 |
| **胡牌** | 基础型 4 面子+1 将；七对、龙七对、豪华七对 |
| **番型** | 基础番、自摸、杠上开花、带根、清一色、七对系列等 |

## 实现检查清单

- [ ] 定缺：每人选缺门，手牌中需有该花色
- [ ] 发牌：庄家 14 张，其余 13 张
- [ ] 吃碰杠胡：优先级 胡 > 杠 > 碰 > 吃
- [ ] 胡牌：缺门检查 + 基础型/七对系列
- [ ] 计分：自摸 3 家付，点炮 1 家付；番数翻倍
