# 四川麻将（川麻）规则技能

本技能提供四川麻将（血战到底 / 血流成河）的完整规则与判定优先级，供实现、判定、计分及 AI 决策时严格遵循。所有判定条件均可量化并映射为代码逻辑。

## 何时使用

- 实现或修改川麻发牌、定缺、行牌、碰/杠/胡逻辑时
- 编写或调试胡牌判定（基础型、七对、龙七对）及缺门校验时
- 实现番型与计分（含杠牌单独计分、双模式结算）时
- 处理流局、漏胡、诈胡/诈杠处罚时
- 实现川麻 AI 定缺、舍牌、进攻与防守策略时

## 核心要点速查

| 模块 | 要点 |
|------|------|
| **牌具** | 108 张，无字牌、无花牌：万/条/筒各 36 张（1–9 各 4 张）；牌型标识如 1w/5t/8b |
| **四大铁律** | ① 缺门：胡牌时手牌花色数只能 1 或 2，3 门全有不能胡；② 牌型：4 面子+1 将 或 七对/龙七对；③ **禁止吃牌**；④ 一炮多响有效 |
| **定缺** | 开局选定定缺花色（万/条/筒），不可改；胡牌前定缺花色必须打完，且手牌花色数≤2 |
| **行牌** | 4 人，庄 14 张先出，闲 13 张；仅摸牌、打牌、碰、杠、胡；杠后从牌墙末尾补 1 张再打 1 张 |
| **胡牌型** | 基础：4 面子（顺/刻/杠）+1 对将；特殊：七对（7 对）、龙七对（七对中含 1 组 4 张相同） |
| **番型** | 平胡 1、对对胡 2、清一色 4、七对 4、龙七对 8、清对 8、清七对 16、全幺九 8；加分项：自摸×2、杠上花/杠上炮/抢杠胡/金钩钓各×2，可叠加 |
| **计分** | 单局得分=基础分×最终番数；自摸 3 家付，点炮仅点炮者付；杠牌单独结算（明杠 3 家各 1 倍，补杠点杠者 2 倍，暗杠 3 家各 2 倍） |
| **双模式** | 血战到底：胡牌即退出，剩 2 人未胡结束；血流成河：胡牌不退出，可多次胡牌，牌墙摸完结束 |

## AI 执行优先级（冲突时按此顺序）

1. **最高**：核心铁律（缺门、牌型、禁止吃、一炮多响）→ 违反则当前操作无效
2. **胡牌判定** → 满足即触发，优先于碰/杠/打牌
3. **定缺与缺门** → 定缺未打完先打定缺，禁止胡牌
4. **杠牌** → 符合则可杠，优先于打牌，次于胡牌
5. **碰牌** → 符合则可碰，优先于打牌，次于胡牌、杠牌
6. **摸牌与打牌** → 无更高优先级时执行
7. **番数与计分** → 胡牌/杠牌后立即结算
8. **双模式适配** → 按当前模式执行胡牌后、流局后逻辑
9. **流局与违规** → 荒牌/四杠/诈胡等按规则处理
10. **策略** → 定缺策略、舍牌、进攻、防守、易错点规避

## 杠牌类型与计分（简要）

- **明杠（点杠）**：手牌 3 张 + 他人打出第 4 张；补牌后打 1 张；其他 3 家各付 1 倍基础分
- **补杠（巴杠）**：已碰的明刻，摸到第 4 张；原点炮者付 2 倍基础分
- **暗杠**：手牌 4 张未亮；补牌后打 1 张；其他 3 家各付 2 倍基础分

## 流局与违规

- **流局**：荒牌（牌墙摸完无人胡）、四杠子、或违规导致无法继续；杠分照算；庄家流局连庄
- **诈胡/诈杠**：向其他 3 家各付 2×基础分，本局继续
- **手牌多/少张**：该玩家本局不可胡牌，无其他处罚
- **漏胡**：该张打出时未报胡，下家操作后本局不可再胡该张，无处罚

## 实现检查清单

- [ ] 牌具：108 张，仅万条筒，无字无花；标识 1w/5t/8b 等
- [ ] 定缺：开局选定，胡牌前定缺打完且手牌花色数≤2
- [ ] 禁止吃牌：任何情况下不触发吃牌
- [ ] 碰/杠/胡：优先级 胡 > 杠 > 碰 > 打牌；杠后末尾补 1 再打 1
- [ ] 胡牌型：4 面+1 将 或 七对/龙七对；龙七对含 1 组 4 张相同
- [ ] 番型与计分：基础番+加分项叠加；自摸/点炮/杠分分开结算
- [ ] 双模式：血战（胡即退）与血流（胡后继续、多次胡）分支正确
- [ ] 一炮多响：多人在同一张牌上胡牌均有效
