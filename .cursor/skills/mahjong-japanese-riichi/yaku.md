# 日本立直麻将 役种全表（天凤/雀魂标准版）

适用规则：天凤/雀魂标准立直麻将，**无地方役、无乱加番**，条件量化、可直接代码判定。符数计算（平和荣和仅 10 符、七对子固定 25 符等）见 [reference.md](reference.md) Skill 11。

## 七、AI 必记核心规则（役种判定约束）

1. **无役 = 绝对不能和了**，宝牌再多也无效。
2. **副露会降番**：一气通贯、混一色、清一色 副露后番数减少。
3. **门前清 = 无任何副露（吃/碰/明杠）**；**暗杠不算副露**，保留门前清。
4. **门前清价值最高**：立直、门清自摸、七对子、两杯口 仅限门前清。
5. **役种可叠加**：例：立直 + 门清自摸 + 平和 = 3 番。
6. **役满覆盖一切**：达成役满，不再计算普通番数。
7. **抢杠**：仅抢**加杠**，不抢暗杠。
