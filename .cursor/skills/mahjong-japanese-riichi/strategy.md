# 日本立直麻将 AI 策略（天凤/雀魂标准·可执行）

与 [reference.md](reference.md) Skill 16–20 对应，优先级从高到低执行。

## 原则

- 防守＞进攻；不点炮＞胡小牌＞做大牌
- 无役不能和了；振听零容忍；门前清优先；宝牌必计

---

## 1. 起手牌型与决策（Skill 16）

- **向听数≤3**：保门前清，快速听牌后立直，争立直/一发/门清自摸，结合宝牌加番
- **向听数 4–5**：攻防兼顾，保留 1–2 张现物，可副露断幺九、役牌加速听牌
- **向听数≥6**：全防守，不副露、不立直，只打牌池现物，避免点炮

起手优先级：① 有役种潜力（役牌对子、断幺九、顺子搭子）→ 优先进攻 ② 宝牌≥2 → 保宝牌可简单役+立直 ③ 无役、宝牌少、向听高 → 只防不攻

---

## 2. 立直时机（Skill 17）

1. **好型听牌（双面/多面听）+ 宝牌≥1** → 立即立直
2. **愚型听牌（嵌张/单吊）+ 宝牌≥2** → 可立直，靠宝牌弥补
3. **好型 + 宝牌=0** → 可立直，争一发、门清自摸
4. **愚型 + 宝牌=0** → 放弃立直，继续换牌优化听牌型
5. **禁止**：向听数≥1（未听牌）、副露后、振听状态禁止立直；立直后不可换牌、不可副露

---

## 3. 舍牌与防守（Skill 18）

**舍牌优先级（防守优先）**：

1. 现物（牌池出现≥2 次的牌）
2. 筋牌（如打过 3w 打 6w，打过 7t 打 4t）
3. 幺九牌（1/9 序数牌、字牌，无役种用途时）
4. 孤张中张（无搭子、无役的 2–8，尽量不打）
5. 危险牌（生张、对手副露花色）→ 绝对不打，除非无牌可打

**针对性防守**：

- 对手立直 → 全防模式，禁止生张、危险牌，可拆搭子
- 对手副露役牌 → 防该花色序数牌、字牌（混一色）
- 对手副露断幺九 → 不打 1/9/字牌，打 2–8 中张现物
- 多人立直 → 只打绝对安全牌（现物、筋牌）

---

## 4. 读牌逻辑（Skill 19）

| 对手行为 | 判断 | 动作 |
|----------|------|------|
| 早切 1/9 | 可能断幺九 | 不打 1/9，打 2–8 现物 |
| 连续切同花色 | 拆搭子，可能已听牌 | 全防，打安全牌 |
| 立直后切熟张 | 好型听牌，听牌范围广 | 只打现物、筋牌，不打中张 |
| 副露役牌+同花色序数 | 可能混一色 | 卡该花色，不打该花色任何牌 |
| 不切幺九、频繁碰 | 可能对对和/四暗刻 | 不打对子牌，打孤张现物 |

---

## 5. 易错点规避（Skill 20）

- 无役绝对不能和了（与川麻区分）
- 振听三种区分清楚，振听禁荣和
- 立直后禁止副露、换牌；立直前确认听牌型
- 符与番分开，按日麻公式计分，不混淆川麻番数
- 流局必算不听罚符；立直棒未和了留至下一局
- 不混淆日麻与川麻：日麻可吃、有役、有振听、符番结合；川麻禁吃、缺门、直接番数
