# 日本立直麻将规则技能

本技能提供日本立直麻将的完整规则与术语，供实现、判定、计分、AI 策略时严格遵循。与中国通用麻将差异大，**无役不能胡、振听不能荣和** 为最高优先级。

## 何时使用

- 实现或修改日麻发牌、行牌、吃碰杠、立直、和了判定时
- 编写役种判定（起和役、番数）、振听判定、宝牌计算时
- 实现符·番·点数计算、流局与不听罚符时
- 需要区分的中国麻将与日麻差异时
- 实现日麻 AI 策略（防守优先、宝牌、立直时机）时

## 核心约束（AI 最高优先级）

1. **无役绝对不能胡**（无屁胡，至少 1 番起和役）
2. **振听只能自摸**，不能荣和
3. 他家立直时优先防守，禁止打生张
4. 宝牌只加番不算役，必须正确计入
5. 门前清番数收益高于副露

## 核心术语速查

| 术语 | 含义 |
|------|------|
| 立直（リーチ） | 门前清听牌宣告，放 1000 点棒，听牌后不能换牌 |
| 荣和 | 别人打出的牌胡牌（点炮胡） |
| 自摸 | 自己摸牌胡牌 |
| 副露 | 吃/碰/明杠，副露后失去门前清 |
| 宝牌（ドラ） | 表示牌下一张，只加番不算役 |
| 里宝牌（裏ドラ） | 立直和了时翻出，额外加番 |
| 振听 | 只能自摸不能荣和的状态（舍牌/同巡/立直振听） |
| 役 | 胡牌资格，至少 1 番 |
| 符·番 | 点数 = 符 × 2^(番+2) × 倍率 |

## 牌具与目标

- **人数**：4 人（东家=親家/庄家，南西北=子家）
- **牌具**：136 张（万/条/筒 + 字牌）+ **红宝牌 3 枚**（赤 5 万、赤 5 筒、赤 5 索各 1 张）
- **目标**：4 面子 + 1 将牌 + **有役** + **非振听** → 和了

## 和了条件（缺一不可）

1. 牌型：4 面子 + 1 将牌（14 张）
2. **至少 1 个役**（起和役）
3. **非振听**（振听时仅能自摸）
4. 无违规（无食替等）

## 振听三种

- **舍牌振听**：自己打过的牌包含自己的和了牌
- **同巡振听**：本巡放弃荣和，本巡不能再荣和
- **立直振听**：立直后和了牌包含自己打过的牌，**永久振听**

## 役种

1 番起和：立直、门前清自摸和、断幺九、役牌、平和、一发、岭上开花、抢杠（仅加杠）、海底摸月、河底捞鱼。2 番～役满全表见 [yaku.md](yaku.md)。门前清 = 无吃/碰/明杠（暗杠不算副露）；副露降番：一气通贯/混一色/清一色。

## 宝牌体系

- **普通宝牌**：表示牌下一张
- **红宝牌**：赤 5 万/筒/索各 1 张，固定加番
- **里宝牌**：立直和了时翻表示牌下的一张
- **杠宝牌/杠里宝牌**：每杠多 1 张表示牌，立直和了时对应里宝

## 与中国麻将核心差异

| 项目 | 中国通用 | 日本立直 |
|------|----------|----------|
| 胡牌门槛 | 可屁胡 | **必须有役** |
| 振听 | 无 | 有，振听只能自摸 |
| 立直/里宝 | 无 | 有 |
| 宝牌 | 无 | 全套体系，只加番不算役 |
| 副露 | 影响小 | 大幅降番 |
| 计分 | 番数计分 | 符+番共同计算 |
